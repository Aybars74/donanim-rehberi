# DonanımRehberi - Bilgisayar Donanım Kataloğu

**BPR201 - İnternet Tabanlı Programlama | Haftalık Proje Ödevi - 2**

## Proje Amacı
Kendi masaüstü bilgisayarını toplamak veya mevcut sistemini yükseltmek isteyen teknoloji meraklıları ve bilgisayar programcılığı öğrencileri için temel bilgisayar donanım bileşenlerini tanıtan, üç sayfalı ve canlı başlık araması destekli bir web rehberi sunmaktır.

## Sayfa Yapısı
- **index.html (Ana Sayfa):** Site tanıtımı, hedef kitle bilgisi ve içerik kataloğuna yönlendirme.
- **icerikler.html (İçerikler):** Temel donanım bileşenlerini tanıtan kartlar ve başlığa göre canlı arama/filtreleme aracı.
- **hakkinda.html (Hakkında):** Projenin seçilme gerekçesi ve ziyaretçilere sağladığı faydalar.

## Çalıştırma Adımları
1. Proje dosyalarını bilgisayarınıza indirin veya klonlayın.
2. `index.html` dosyasına çift tıklayarak herhangi bir modern web tarayıcısında açın (veya VS Code / Codespaces üzerinde **Live Server** eklentisi ile çalıştırın).
3. Üst menüden **İçerikler** sayfasına geçerek donanım başlıkları üzerinde arama yapabilirsiniz.
